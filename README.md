# Ollama Chat — чат с локальной ИИ в Godot

Маленькое приложение на Godot 4, которое общается с моделью через
[Ollama](https://ollama.com) — локально или через любой OpenAI-совместимый API
(Ollama Cloud, OpenAI, Groq, OpenRouter, DeepSeek). По умолчанию всё работает на
вашей машине, без ключей и интернета. Ответ печатается потоком, поддерживаются
Markdown, отмена генерации,
собственные «модели» — персонажи с именем, основой и темпераментом — и
автоматическое сохранение всех переписок. Перед первым сообщением приложение
спрашивает, с кем поговорим: персонаж или обычная модель.

## Что умеет

- **Два провайдера**: локальный Ollama (`/api/tags`, `/api/chat`) и любой
  OpenAI-совместимый API (`/models`, `/chat/completions`). См. ниже.
- Список моделей (`GET /api/tags` или `/v1/models`) и проверка соединения.
- Потоковый ответ токен за токеном (`stream: true`) или обычный JSON-ответ.
- Кнопка «Стоп» — генерацию можно прервать на середине.
- Markdown в ответах: **жирный**, *курсив*, `код`, блоки кода, списки, ссылки.
- Настройки сохраняются в `user://ollama_chat.cfg`: провайдер, адрес сервера,
  ключ, модель, системный промпт, температура, стриминг.
- **Стартовый экран «С кем поговорим?»** — выбор персонажа, обычной модели или
  продолжение последней переписки одним нажатием. См. ниже.
- **Переписки сохраняются автоматически** — список диалогов слева, возврат к
  любому из них, переключение и удаление. См. ниже.
- **Свои модели (персонажи)** — настройка уже установленной модели: имя, основа,
  темперамент. См. ниже.

## Свои модели: имя, основа, темперамент

Обучить модель внутри приложения нельзя, зато можно описать её характер.
Кнопка **«+ Создать»** в блоке «МОИ МОДЕЛИ» открывает форму:

| Поле | Что это |
| --- | --- |
| **Имя** | Как модель называется в чате: «Бородач», «Редактор», «Пират». |
| **Основа** | Уже установленная модель Ollama, которая будет отвечать (`llama3.2:latest`, `qwen2.5-coder:7b`, …). |
| **Темперамент** | Кнопки-черты, которые нажимаются и отжимаются: «Дружелюбный», «Сарказм», «Коротко», «Подробно», «Учитель», «Честно о незнании» и др. |

Из имени и темперамента приложение собирает системный промпт — его видно в
форме в блоке **«Системный промпт — предпросмотр»**. Взаимоисключающие черты
(например, «Коротко» и «Подробно») отжимают друг друга автоматически.

Как это работает:

```
«Бородач» + основа qwen2.5-coder:7b + темперамент [Дружелюбный, Коротко]
   ↓
системный промпт
   Тебя зовут Бородач.
   Ты — собеседник в чате на локальной модели «qwen2.5-coder:7b».
   Твой темперамент:
   — Общайся дружелюбно и тепло, обращайся на «ты», подбадривай собеседника.
   — Отвечай максимально коротко — обычно 1–3 предложения…
   ↓
POST /api/chat { model: "qwen2.5-coder:7b", messages: [system, …] }
```

- Персонажи хранятся в `user://personas.json`.
- Выбранный персонаж подсвечивается в шапке чата (`Бородач · qwen2.5-coder:7b`),
  его имя подписывает ответы.
- Если в «БАЗОВЫХ МОДЕЛЯХ» выбрать другую модель, она станет основой текущего
  персонажа (об этом сообщит подсказка внизу).
- «Настроить» — правка имени, основы и темперамента; там же «Удалить» (в два
  нажатия, чтобы случайно не потерять персонажа).
- «— без персонажа —» возвращает обычный режим: отвечает выбранная базовая
  модель, а системный промпт из настроек используется как есть.

## Провайдеры: локально или облако

В «НАСТРОЙКАХ» есть переключатель **Провайдер**:

| Провайдер | Что это | Адрес |
| --- | --- | --- |
| **Ollama (локально)** | модели на вашей машине, ключ не нужен | `http://localhost:11434` |
| **OpenAI-совместимый API** | облако или другой сервер с тем же протоколом | `https://ollama.com/v1` и т. п. |

У каждого провайдера свой адрес и своё поле ключа: приложение запоминает их по
отдельности, поэтому переключение «туда-обратно» не заставляет вводить всё заново.

### Ollama Cloud (быстрее, чем локальная модель на слабом ноутбуке)

1. Заведите ключ: `ollama signin` в терминале или на [ollama.com](https://ollama.com) → API keys.
2. Провайдер → **OpenAI-совместимый API**.
3. Адрес: `https://ollama.com/v1` (именно с `/v1` — это OpenAI-совместимый вход).
4. Ключ: ваш `OLLAMA_API_KEY` (начинается с `sk-`).
5. «Обновить список моделей» — придут облачные модели, например `gpt-oss:120b`.

### OpenAI, Groq, OpenRouter, DeepSeek

Всё то же самое: адрес провайдера вместе с версией и ключ.

| Сервис | Адрес |
| --- | --- |
| OpenAI | `https://api.openai.com/v1` |
| Groq | `https://api.groq.com/openai/v1` |
| OpenRouter | `https://openrouter.ai/api/v1` |
| DeepSeek | `https://api.deepseek.com/v1` |
| LM Studio / vLLM (свой сервер) | `http://localhost:1234/v1` |

Что происходит с запросом: приложение шлёт `POST <адрес>/chat/completions` с
`Authorization: Bearer <ключ>` и читает ответ как поток SSE (`data: {...}`,
`data: [DONE]`). В локальном режиме — `POST /api/chat` с NDJSON.

### Про ключ и приватность

- Ключ лежит только в `user://ollama_chat.cfg` на вашем компьютере (поле ввода
  скрыто звёздочками) и уходит исключительно на выбранный адрес.
- В облачном режиме сообщения переписки отправляются провайдеру — это его работа.
  В локальном режиме ничего не покидает машину.
- Ошибки объясняются по-человечески: 401 — «Неверный API-ключ», 403, 429 и т. п.
- Персонажи и переписки работают в обоих режимах: персонаж просто отвечает
  облачной моделью, выбранной как основа.

## Стартовый экран: с кем поговорим

Пока переписка не начата, вместо пустого чата показывается стартовый экран:

- **ПРОДОЛЖИТЬ** — последняя переписка одной кнопкой (заголовок и когда
  обновлялась видны прямо на ней). Блок появляется, только если сохранённые
  диалоги уже есть.
- **ПЕРСОНАЖИ** — список своих моделей: имя и основа на карточке, темперамент в
  подсказке. Нажатие сразу выбирает персонажа.
- **+ Создать персонажа** — открывает ту же форму, что и кнопка в сайдбаре.
- **ИЛИ ПРОСТО МОДЕЛЬ** — сетка установленных моделей Ollama для обычного
  диалога без персонажа. Если список ещё не загружен, экран подскажет запустить
  `ollama serve` и нажать «Обновить список моделей».

Экран появляется при запуске, после **«+ Диалог»** и после удаления открытой
переписки. Как только выбрали персонажа или модель — (или отправили первое
сообщение) — он уступает место чату. Выбранная модель и персонаж остаются в
сайдбаре, поменять их можно в любой момент.

## Переписки

Диалог сохраняется сам — ничего нажимать не нужно. В сайдбаре, в блоке
**«ПЕРЕПИСКИ»**, виден список всех диалогов (заголовок + когда обновлялся):

- Заголовок берётся из первого сообщения пользователя, переименовывать вручную
  не нужно.
- Запись на диск происходит после каждого сообщения и после ответа модели, так
  что при аварийном закрытии ничего не теряется. Если приложение закрыли во
  время генерации, уже написанное пользователем сообщение остаётся в файле.
- При запуске сначала открывается экран выбора: последнюю переписку можно
  продолжить кнопкой **«Продолжить»** или выбрать в списке слева — сообщения
  восстановятся вместе с её персонажем и моделью.
- Каждая переписка помнит своего персонажа и модель: открыли старый диалог —
  персонаж и модель переключились сами.
- **«+ Диалог»** — новый диалог. Пустые диалоги не создаются: переписка
  появляется в списке только после первого сообщения.
- **«Удалить»** удаляет открытую переписку (в два нажатия, чтобы случайно не
  потерять).
- Если ответ модели сорвался, а сообщение было единственным — пустая переписка
  не остаётся в списке.

Формат — один JSON на диалог в `user://chats/<id>.json`:

```json
{
  "id": "c_123456_1",
  "title": "Привет! Расскажи про космос",
  "created_at": 1762540000,
  "updated_at": 1762540060,
  "persona_id": "p_98765_1",
  "persona_name": "Бородач",
  "model": "qwen2.5-coder:7b",
  "messages": [
    {"role": "user", "content": "Привет! Расскажи про космос"},
    {"role": "assistant", "content": "…", "speaker": "Бородач"}
  ]
}
```

## Запуск

1. Установите [Ollama](https://ollama.com/download) и запустите её:
   ```bash
   ollama serve
   ollama pull llama3.2
   ```
2. Откройте проект в Godot 4.7+ (или запустите собранный бинарник) и нажмите F5.
3. В приложении: `http://localhost:11434` → «Обновить список моделей» → на
   стартовом экране выберите персонажа или модель → пишите.

Без Ollama на компьютере можно сразу перейти на облако: в «НАСТРОЙКАХ» выберите
провайдера **OpenAI-совместимый API**, адрес `https://ollama.com/v1`, вставьте
ключ и нажмите «Обновить список моделей».

Горячие клавиши в поле ввода: `Enter` — отправить, `Shift+Enter` — новая строка,
`Ctrl+Enter` — тоже отправить.

## Тесты

```bash
# мок-сервер Ollama (список моделей, стриминг, ошибки, отмена)
python3 tools/mock_ollama.py --port 11499 &

# логика: Markdown, клиент Ollama и OpenAI-совместимого API, хранилище
godot --headless --path . --script tests/run_tests.gd

# интерфейс: стартовый экран, чат, провайдеры, персонажи, переписки
godot --headless --path . --script tests/run_ui_test.gd
```

Скриншоты для документации (нужен X-сервер):

```bash
python3 tools/mock_ollama.py --port 11499 &
xvfb-run -s "-screen 0 1280x900x24" godot --path . --script tools/screenshot.gd
```

## Структура

```
scenes/main.tscn          интерфейс: сайдбар, чат, поле ввода
scripts/main.gd           логика экрана, связь клиента, персонажей и интерфейса
scripts/ollama_client.gd  HTTP-клиент: Ollama (/api/chat) и OpenAI-совместимые API
scripts/personas.gd       персонажи: каталог темпераментов, JSON, сборка промпта
scripts/persona_editor.gd форма «Новая модель»: имя, основа, темперамент
scripts/start_screen.gd   стартовый экран «С кем поговорим?»: персонажи и модели
scripts/chat_store.gd    переписки: JSON-файлы, заголовки, время, удаление
scripts/chat_bubble.gd    пузырь сообщения
scripts/markdown.gd       Markdown → BBCode
scripts/ui_theme.gd       тёмная тема кодом
examples/chat_overlay.gd  пример: чат как меню поверх игры (Esc)
tests/                    headless-тесты логики и интерфейса
tools/mock_ollama.py      заглушка API Ollama для тестов
```
